# Experiment 039 — Protocol Grounding

## Question

Can MORPHS use host-supplied protocol facts as constraints while routing genuinely unknown mechanisms into experimentation instead of rediscovering the constitution?

## Core rule

HOST FACT → CONSTRAINT

UNKNOWN → EXPERIMENT

CONTRADICTION → PRESERVE + REOBSERVE

KNOWN FAILURE → REGRESSION PROTECTION

The experiment deliberately keeps protocol status separate from epistemic research status.

## Cases

- A host fact about verifier authority is used directly as a constraint.
- An unknown question about transfer to an external runtime becomes an experiment rather than receiving an answer from the protocol.
- A verifier disagreement is preserved as contradiction and blocks silent source selection.
- The known 038 fixture failure becomes a regression target rather than disappearing from the research record.

## Epistemic status

EXPERIMENTALLY_SUPPORTED

Scope: deterministic protocol-grounding simulator.

Limitation: this tests routing discipline, not autonomous protocol construction or unrestricted research planning.

## Research value

The protocol becomes a high-level prior/constitution:
- it tells MORPHS what is already fixed
- it tells MORPHS what must remain protected
- it tells MORPHS how to treat evidence and failure
- it leaves unknown mechanisms to experiments

This reduces wasted rediscovery without contaminating experiments with answers to questions that remain open.
